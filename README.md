# Rynek

Plugin rynku (auction house) dla Paper 1.21 z GUI.

- Komendy: `/ah open`, `/ah sell <cena>`, `/ah search <nazwa>` (alias `/rynek otworz|wystaw|szukaj`), `/ah reload`
- Wymaga: Vault + plugin ekonomii (np. EssentialsX)
- Wyszukiwanie rozumie polskie nazwy (miecz, kilof, klata, diamentowy...). Slownik: `plugins/Rynek/search-pl.txt`
- Gotowy plik .jar: zakladka **Actions** -> ostatni przebieg -> **Artifacts**
